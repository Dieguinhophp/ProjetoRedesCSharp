# EcoFire Connect
# Sistema Inteligente de Comunicação Operacional para Combate a Incêndios Florestais

EcoFire Connect é uma aplicação desktop desenvolvida em C# utilizando Windows Forms, criada com foco na comunicação operacional entre equipes de prevenção e combate a incêndios florestais.

O sistema foi inspirado nas necessidades do Centro Nacional de Prevenção e Combate aos Incêndios Florestais (Prevfogo), oferecendo uma plataforma de comunicação em tempo real entre agentes, brigadistas e coordenadores em rede local.

A aplicação utiliza arquitetura cliente-servidor com comunicação TCP/IP, permitindo troca instantânea de mensagens, gerenciamento de usuários conectados, atualização de status operacional e transmissão de vídeo via webcam entre diferentes máquinas.

O projeto também conta com integração com banco de dados SQLite para autenticação de usuários, armazenamento de cargos hierárquicos e controle de status das equipes em operação.

## Principais funcionalidades

* Login e registro de usuários
* Sistema de cargos hieráricos
* Comunicação em tempo real via TCP/IP
* Lista de usuários online
* Atualização de status operacional
* Videochamada via webcam
* Banco de dados SQLite
* Interface personalizada com identidade visual ambiental
* Arquitetura cliente-servidor distribuída

## Tecnologias utilizadas

* C#
* Windows Forms
* SQLite
* TCP/IP Sockets
* OpenCvSharp
* .NET

O projeto foi desenvolvido com foco educacional e profissional, simulando um sistema corporativo de comunicação utilizado em operações ambientais e emergenciais.
